## Solución y arquitectura

La aplicación está dividida en tres piezas, todas en planes gratuitos:

| Pieza         | Tecnología                 | Despliegue |
| ------------- | -------------------------- | ---------- |
| Frontend      | React + Vite + TypeScript  | Vercel     |
| API           | Node.js + Express + Prisma | Render     |
| Base de datos | PostgreSQL                 | Neon       |

Incluye un panel de administración protegido para ver, editar y eliminar los reportes mensuales, y genera constancias en PDF.

La regla de negocio central define quién cuenta en el indicador: un estudiante está **activo** si asistió al menos al 50 % de los ensayos de las últimas 4 semanas (28 días). Solo los estudiantes activos cuentan en la demografía del indicador.

Algunas rutas de la API:

```text
GET    /api/agrupaciones
GET    /api/agrupaciones/:id/demografia-activa
POST   /api/reportes-mensuales
GET    /api/admin/reportes-mensuales        (requiere admin)
PUT    /api/admin/reportes-mensuales/:id    (requiere admin)
DELETE /api/admin/reportes-mensuales/:id    (requiere admin)
```
