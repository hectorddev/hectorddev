# Fuentes para imágenes OG

Archivos WOFF estáticos usados por `next/og` (Satori no soporta WOFF2) al
generar las imágenes Open Graph en `src/lib/og.tsx`.

- Bricolage Grotesque 800 — SIL Open Font License 1.1
- JetBrains Mono 500 — SIL Open Font License 1.1

Fuente: Fontsource (https://fontsource.org), subconjunto latin.
